3. Pipeline Técnico

┌─────────────┐    ┌──────────────────┐    ┌────────────────┐    ┌──────────────┐    ┌──────────────────┐
│  DATOS      │───▶│  FEATURE ENG.    │───▶│  FEATURE SEL.  │───▶│  MODELADO    │───▶│  SUBMISSION    │
│  train+test │    │  Lags, deltas,   │    │  Var.cero →    │    │  LightGBM,   │    │  id_cliente,   │
│  (120k filas)    │  ventanas 3m,    │    │  Corr >0.95 →  │    │  XGBoost,    │    │  prediccion    │
└─────────────┘    │  TE temporal,    │    │  Top-K LGBM    │    │  CatBoost,   │    └──────────────┘
                   │  OHE categóricas │    │  (50 finales)  │    │  RF + Optuna │
                   └──────────────────┘    └────────────────┘    │  Val. Temporal│
                                                                │  (3 últimos m)│
                                                                └──────────────┘
Reglas anti-leakage: Validación temporal (no aleatoria) • Lags/ventanas calendario-conscientes • Target Encoding solo con pasado • Selección features solo en train • Sin id_cliente/mes como predictoras

7. Cómo Ejecutar

# Instalación
python3 -m venv .venv && source .venv/bin/activate
pip install -U pandas numpy scikit-learn lightgbm xgboost catboost optuna

# Ejecución completa (~2 min)
python Pipeline_DF_WCB.py --datos . --salida ./salida/submission.csv --trials 30 --meses-val 3 --n-seeds 3

# Ejecución rápida test (~30 seg)
python Pipeline_DF_WCB.py --datos . --salida ./salida/prueba.csv --trials 0 --n-seeds 1
